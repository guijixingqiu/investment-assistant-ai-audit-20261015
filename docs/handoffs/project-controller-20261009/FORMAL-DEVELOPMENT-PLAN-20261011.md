- A12.2：报告型正式投资决定必须绑定 current、完整、已确认报告及对应证据、估值、技术和适用资产快照身份；旧报告可读可比但不能冒充current用于新正式决定。报告确认和决定分别操作，记录方向、理由、期限、价格/研究仓位条件、风险、失效、复核日期、分歧与证据版本；普通人工判断沿A12.1独立路径。正式决定纠错生成新版本，不原地改历史；无可靠资产只能给研究级假设仓位。
- A12.3：支持买入、观察、加仓、持有、减仓、卖出、放弃、等待证据八类不执行方向。候选筛选/AI建议不能自动成为决定。
- A12.4：股票/报告/证据身份错误和该正式动作所需关键资料缺失硬阻断；个人仓位/集中度/亏损预算等风险触发强警告，可按已批准规则二次确认并永久保留覆盖理由。不能把报告型前提强加到普通人工路径。
- A12.5：保存与重复提交可核清；系统建议、Owner决定及后来事实分开保存。决定状态保留草稿、有效、待复核、被替代、已失效、已复盘及原因/时间；失效由Owner确认，不因到期自动撤销。无订单或资产自动写入。

### A13 持续跟踪、Today与通知

- A13.1：稳定低频来源更新分通用事件与公司KPI；新信息说明影响哪个假设、条件或反证，并保留新旧事实与来源版本。
- A13.2：规则含变量、来源、频率、阈值、理由和版本；AI可提议，Owner确认后生效，普通页面打开不改规则。
- A13.3：Today展开一项最高优先可执行动作，其余可查看；身份/资料版本点击重读。去重、稍后、解决、重开、过期和合并行为清楚。
- A13.4：高影响可在Owner开启后通知，中影响只进Today，低影响只进档案；免打扰/时区有效。公告、新闻和KPI按合理频率，港股行情/技术收盘后批量处理，不做盘中高频；采集失败不能冒充无变化。
- A13.5：排序说明影响等级、失效/复核期限、事件时间；打开卡片不自动解决。只有新材料版本、重要性上升或决定重新受影响才重开；无明确有效期不自动过期，过期保留历史。Owner选择稍后回流时间。
- A13.6：普通指标波动和日涨跌不制造Today待办；仅结构性技术变化进入。研究任务仅失败、待吸收、资料变化需重做进入Today，普通进度留Research。自动采集不得冻结证据、改报告/决定/监控规则，解决/稍后等操作回读后才成功。

### A14 复盘与下次研究复用

- A14.1：同一判断的计划日期保存回读，未到期不催办，到期准确关联；提前复盘后不回到未完成。
- A14.2：过程与结果分开复盘；当时判断/资料/风险覆盖理由保持原貌，后续事实和遗漏反证追加记录。
- A14.3：教训、下一问题及适用资料由Owner选择带入新研究，不把全部历史或模型总结无差别塞入上下文；复盘实际解决Today对应事项。
- A14.4：保存当时报告、决定、市场和适用资产快照；复盘逻辑、反证、数据、风险纪律、系统判断与Owner覆盖。样本不足不生成伪精确评分，不评价Owner；发现失效只引向重研/新决定，不改旧历史或产品硬规则。

### A15 持仓背景和资产研究

- A15.1：手工/CSV数量、逐笔成本和确认时间可保存并读回同一快照；未知保存结果保留同一请求直到核清，跨弹窗/界面不静默重建。
- A15.2：持仓时间、行情时间、来源和账户范围分别呈现；研究影响绑定对应公司与快照。缺行情/持仓不伪造零值、不挡普通研究。
- A15.3：旧成交历史只读用途和新建退出状态明确，保留已有历史/调用依赖；不恢复完整账本、券商写入或真实交易。
- A15.4：私人资产只在授权本地范围使用，云端研究和外部审核不发送持仓/账户；资产不可用时提供真实原因和适用独立入口。

### A16 多公司与真正可比同行

- A16.1：至少第二种商业模式的真实流程可用，复用身份/数据/研究机制，不复制单股硬编码样板。
- A16.2：完整研究保持原明确要求的3—5家真正可比公司，说明比较维度、可比性和排除理由。若实际不足，给受限结果及原因，不能编造同行或擅自把完整标准降为2家。
- A16.3：比较成立条件、估值假设、风险、资料充分度、共同暴露；日期、币种、范围和版本可比较，必要差异明示；现金/暂不选择是合法结果。
- A16.4：已有两公司四路读取不是本项完成证据；同行资料允许适用的HTML/提供商来源，不人为强制每项有PDF页。

### A17 本地资料处理与窄自动化

- A17.1：真实扫描PDF样本可本地处理并回原件/位置人工核对；OCR/表格提取错误可修订，不自动变核实事实。
- A17.2：中文、繁体、同义词、表格文本按真实研究问题检查；已有全文检索满足时复用，不先重建搜索。
- A17.3：至少一个实际重复资料整理环节通过现有工具自动化，展示原需人工动作及减少的动作/可核对输出；不搭通用Agent平台。
- A17.4：复杂批量PDF财务抽取后排，不能遮蔽本项已批准的扫描、检索、校对和整理需求。

### A18 按需第二意见

- A18.2：预览、显式发送、结果/历史绑定同一选定证据包、公司、报告和版本；展示分歧、新反证和缺口，不投票冒充正确。
- A18.3：单独显示成本并计入适用累计预算；失败/未知发送可核清，无未经确认备用发送；不发送敏感资产，不改正式决定。

### A19 备份、导出、恢复、生命周期与隐私

- A19.1：每日及正式确认报告/决定/复盘后三类事件生成范围正确快照；排除凭据、缓存和未吸收临时内容，覆盖已保存正式对象和关联来源。
- A19.2：本地完整manifest/hash后原子移入同步目录；默认30日/12周/12月保留；云端同步未证明显示UNKNOWN，不把本地文件存在当云端成功。
- A19.3：无PDF和含真实原件两种备份均可隔离恢复、重开来源/报告/决定/复盘；实际替换前先生成当前保护快照、完成临时校验，再由Owner确认。开发不自动替换真实数据。
- A19.4：按股票/全部导出：PDF供阅读，JSON/CSV供迁移，原件保留原格式和hash清单；默认排除敏感内容，导出范围明确。
- A19.5：临时内容默认30天，可选7天/30天/不保留；长期记忆限正式证据、报告、决定、修正、复盘、确认偏好和监控规则。正式历史追加版本；删除先退出UI/搜索/AI上下文，二次确认后清正文和派生索引，仅留无正文的最小删除记录，不连带删其他历史。
- A19.6：删除进入下一备份，并提示旧云端历史版本可能仍有内容；删除/恢复/批量导出显式确认并回读。备份失败或长期不同步进Today受阻项，成功不制造通知。Owner可改保留数；普通同步目录复用现有客户端，不自建各网盘SDK，不新增应用层端到端加密。
